## 🎯 What is Society Connect?

Tired of endless WhatsApp groups, missed notices, and confusing complaint trails? **Society Connect** is your all-in-one digital solution to modernize apartment/housing society management.

It's a **secure, role-based web application** that bridges the communication gap between residents and the administrative body, ensuring a smooth, transparent, and hassle-free living experience for everyone. Think of it as the society's virtual front office, open 24/7!

---

## 🚀 Key Features: Your Digital Amenities

We've packed this portal with features designed to simplify society life.

### For Residents (The Heart of the Society)

* **📢 Instant Updates:** Never miss a critical update again! View all **Announcements** (events, maintenance, urgent notices) on a dedicated board.
* **🛠️ Complaint in a Snap:** Log a new **Complaint** in seconds. Select a category (Maintenance, Security, Parking), set a priority, and even attach a photo for clarity.
* **🔎 Know the Status:** Track the journey of your issues with a personal **Dashboard** showing real-time status updates: `New`, `In Progress`, `Resolved`.
* **📞 Emergency Ready:** Quick access to essential **Emergency & Service Contacts** (plumbers, electricians, security).

### For Admins (The Backbone of the Society)

* **📊 Command Center Dashboard:** A powerful overview showing total complaints, the **resolution rate**, and current pending issues.
* **✅ Efficient Triage:** A centralized **Complaint Management** system to review, prioritize, and update the status of resident issues with ease.
* **✍️ Announcement Power:** Instantly draft and publish official **Announcements** with specific tags (e.g., *Urgent*, *Event*, *Maintenance*) to ensure residents see what matters most.

## 🚦 Getting Started (Local Development)

Want to peek under the hood or contribute? It's straightforward!

### Prerequisites

You just need a modern web browser and **Git**.

### Installation

1.  **Clone the Repository:**
    ```bash
    git clone [https://github.com/omkale18-dev/cep-project.git](https://github.com/omkale18-dev/cep-project.git)
    ```
2.  **Navigate to the Folder:**
    ```bash
    cd cep-project
    ```
3.  **Launch the App:**
    Simply open the `index.html` file in your favorite browser (e.g., Chrome, Firefox). No backend server is required to run the client-side code!
